# Learn SecByte FTP, Shell, File Hunt & Gobuster CTF Labs

A focused collection of **cybersecurity labs, CTF labs, hands-on cybersecurity labs, ethical hacking labs, and penetration testing labs** from Learn SecByte.

This collection covers **hash cracking, pivoting, file discovery, FTP enumeration, FTP uploads, shell stabilization, shell-based access, Gobuster filesystem hunting, hidden HTTP paths, and root-focused CTF scenarios**.

The labs are useful for cybersecurity students, CTF players, pentesters, SOC analysts, and security learners practicing reconnaissance and authorized security testing.

## Learning Path

### 1. Begin With File & Web Discovery

Start with:

- File Hunt Hidden Paths
- HTTP Hidden Paths
- Gobuster Filesystem Hunt

Build a foundation in path and file enumeration.

### 2. Explore FTP Reconnaissance

Continue with:

- FTP in Plain Sight
- FTP Vault Break-In
- FTP Upload Trap
- FTP Shell Springboard

Study FTP discovery, access, upload, and shell-related concepts.

### 3. Practice Web & Shell Concepts

Then work through:

- Shell Upload Siege
- Shellstabilize FTP to Root
- Shell Keys Root Tricks

Connect enumeration findings with shell and root-focused scenarios.

### 4. Study Credentials & Pivoting

Finish with:

- Hash Trail Crack Pivot
- Shreks Shadow Shift

Review hash, credential, shadow-file, and pivoting themes represented by the exercises.

## How to Use the Labs

1. Select a lab from the collection.
2. Read its instructions and identify the objective.
3. Work only against the authorized CTF environment.
4. Begin with systematic reconnaissance.
5. Record discovered files, paths, services, credentials, and other findings.
6. Document the reasoning behind each step.
7. Review the defensive security lesson after completing the challenge.

Skills represented across this collection include:

- FTP reconnaissance
- FTP security
- File enumeration
- Hidden-path discovery
- Gobuster
- HTTP reconnaissance
- Hash and credential security
- Linux security
- Shell stabilization
- Shell-related CTF scenarios
- Pivoting concepts
- Privilege-escalation concepts
